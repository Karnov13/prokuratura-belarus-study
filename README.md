# Прокуратура Республики Беларусь — учебный навигатор

Статический учебный сайт: **Структура**, **Обращение**, **Поступление**, **Направления деятельности прокуратуры**, **Интерактивы**. HTML/CSS/JavaScript; без бэкенда, сторонних зависимостей, аккаунтов и сбора обращений. Автор идеи и создатель — **Дюбкина Дарья Дмитриевна**.

## Запуск

Нужны Node.js 24+ и Python 3 для удобного локального HTTP-сервера.

```powershell
cd 'E:\Codex проекты и чаты\Сайт про прокуратуру'
node --test
node scripts/build.mjs
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4173/`. Не открывайте index.html через `file://`: браузер ограничивает загрузку JSON и ES-модулей. Для быстрой работы с исходниками сервер можно запустить без `--directory dist`; полноценная версия без JavaScript добавляется именно при сборке.

Прямые ссылки: `#/structure`, `#/appeals`, `#/career`, `#/activities`, `#/interactive`. Ссылки на отдельные блоки имеют вид `#/career?section=section-2` или `#/interactive?section=quiz-block`; они поддерживают копирование и перезагрузку. Все файлы подключаются относительными путями; проект работает в подпути `https://USERNAME.github.io/REPOSITORY/`.

## Данные и источники

- `data/structure.json`: органы, родительские связи, адреса, подтверждённые должностные лица и источники. `checkedAt` — дата просмотра источника, а не гарантия неизменности данных.
- `data/content.json`: учебные материалы, упражнения и реестр источников. Статус проверки привязан к материалу и источнику. Неподтверждённые сведения обозначены текстом.
- `docs/structure-sources.md`, другие исследовательские заметки в `docs/`: границы исследования и подтверждения. Полный перечень в каталоге не означает полный кадровый состав.
- `assets/SOURCE.md`: происхождение изображения символа Академии. Используется выбранный пользователем 08.11.2026 файл `assets/academy-symbol-user-selected.png` (600×314 px) без изменений: весь прямоугольный синий фон, исходные пропорции и детали сохранены. Предыдущий JPG и отклонённые кандидаты на сайте не подключены; официальный мастер не заявляется.

Не заменяйте пустые поля догадками. Перед содержательным обновлением сверяйте первичный официальный источник и указывайте дату просмотра. После правок выполните `node --test` и `node scripts/build.mjs`; обновлённые материалы войдут в доступную без JavaScript версию.

## Интерфейс

В структуре выберите регион и орган; поиск работает по названию, региону, адресу и ФИО. Фильтры сочетаются. Карточка показывает подчинение, доступные ФИО, адрес и ссылки. Отсутствие сведений не означает отсутствия органа или должности.

Квиз проверяет заполненную попытку, показывает результат и пояснения. Кнопка «Пройти заново» очищает ответы. Загадки и ребусы принимают ответ, дают подсказку и раскрывают решение. Регистр, пунктуация и различие «е/ё» при проверке не учитываются. Ответы хранятся только в памяти страницы и исчезают при смене раздела или перезагрузке.

Предусмотрены клавиатурное управление, видимый фокус, мобильное меню с Escape, reduced motion и версия чтения без JavaScript в собранном сайте. Сайт не отправляет обращения и не заменяет официальный сайт прокуратуры.
