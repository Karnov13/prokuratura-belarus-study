# Отчёт реализатора — подготовка выпуска 08.11.2026

## Реализованный сайт

HTML/CSS/JavaScript без бэкенда и сторонних зависимостей. Пять разделов: Структура, Обращение, Поступление, Направления деятельности прокуратуры, Интерактивы. Hash-маршруты поддерживают подпуть Pages, Back и прямые ссылки. Ссылка вида `#/career?section=section-2` сохраняет страницу и блок при копировании, новой вкладке и перезагрузке. Переход внутри страницы не сбрасывает ответы; skip-link переносит фокус без изменения URL.

Каталог сочетает поиск по названию/адресу/региону/ФИО с фильтрами региона и уровня. Регион раскрывается в список органов, выбранная карточка появляется справа, на телефоне — ниже списка. Подчинение, подтверждённые ФИО, адрес, дата просмотра и источники показаны отдельно; индивидуальные источники должностных лиц поддержаны. Обходы защищены от циклов; отсутствующие сведения явно обозначены. JSON загружаются независимо, ошибка одного файла не лишает доступа к другому; есть повтор загрузки.

Учебные статьи имеют оглавление, источники и статусы проверки. Дата просмотра не заявляется подтверждением действующей редакции. Квиз проверяет завершённую попытку, показывает правильные ответы и объяснения, перезапускается. Загадки и ребусы принимают ответ, предоставляют подсказку и решение.

Дизайн: тёмно-синяя шапка, светлое поле чтения, локальные Georgia/Arial, видимый фокус, reduced motion и forced colors. Меню действует при ширине менее 1100px; Escape обрабатывается на всей шапке, включая кнопку. Автор Дюбкина Дарья Дмитриевна указан справа в подвале, в потоке документа.

## Сборка и публикация

`node scripts/build.mjs` формирует `dist/` по разрешённому списку: HTML/CSS, два браузерных JS, два JSON, выбранный PNG и `.nojekyll`. Документы, дизайн-макеты, тесты, research-материалы и код сборки в Pages-артефакт не входят. Сборка валидирует данные и генерирует полную версию чтения без JavaScript с источниками и раскрываемыми решениями. HTML экранируется, внешние ссылки допускают только HTTP/HTTPS.

Workflow `.github/workflows/pages.yml`: Node24 → тесты → сборка → Pages artifact → deploy. Запускается при push в main либо вручную. npm не требуется.
