# Добавление загадок в «Интерактивы»

1. Перенести пары вопрос и ответ из проверенной выписки DOCX в `data/content.json` в исходном порядке.
2. Дополнить `scripts/rebuses.js` общим представлением вкладки: ссылки на «Ребусы» и «Загадки», заголовки блоков, одна колонка вопросов и нативное раскрытие ответа. Открывать новый блок по устойчивому якорю и сохранять переходы Back.
3. Использовать то же представление в `scripts/app.js` и `scripts/build.mjs`, меняя только формат якорей для версии без JavaScript. Применить существующие размеры текста и зафиксировать изменения в `styles.css` и `README.md`.
4. Проверить в `tests/` корректность данных и наличие закрытого ответа в сборке. Запустить `node --test` и сборку, сверить порядок загадок и исходные JPEG ребусов.

Результат готов для ревью, когда вопросы видны, каждый ответ раскрывается отдельно, обе группы доступны с JavaScript и без него, а все 11 изображений ребусов остаются на своих местах.

В исходнике девять пар. В пятой паре строка «Ответ надо с обоснованием» показана в условии. Под раскрытием остаются ответы А–Г и ссылки на нормы. Формулировки из DOCX и их порядок сохранены.
