# Примечания к текстам источников и оговорок

Редакторская выжимка для раскрываемого блока «Источники» и коротких предупреждений рядом с материалом. Сверена с `data/content.json`; юридические тексты, списки и исходные статусы не меняются. Пустое предупреждение означает, что в текущей записи не отмечено отдельной неопределённости или расхождения.
