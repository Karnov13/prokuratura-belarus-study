# Источники и аудит каталога прокуратур РБ

Проверено: 2026-11-08. Официальные страницы prokuratura.gov.by отвечали HTTP 200. Все строки таблиц «Личный прием» извлечены из HTML всех семи региональных страниц; речь не только о первом видимом контактном списке. Каждая строка проверялась целиком: ФИО и должность прочитаны из одной строки таблицы, затем должность сопоставлена с названием органа в том же региональном разделе. Дата публикации таблиц не обозначена; `checkedAt` — дата просмотра, `publishedAt` оставлен `null`.

## Результат покрытия

В JSON 149 органов: Генеральная прокуратура и 148 записей семи региональных каталогов. Из семи региональных HTML извлечено 166 строк ФИО и должностей. Они однозначно сопоставлены с 147 органами; множественные строки относятся к руководителям и заместителям областных прокуратур и прокуратуры города Минска. Вместе с Генеральной прокуратурой подтверждённые ФИО есть у 148 органов из 149.

Единственная запись без ФИО — прокуратура Брестского района: она присутствует в контактной таблице Брестской области, но в извлечённой таблице личного приёма отдельная строка прокурора этого района отсутствует. Это не вывод о вакантности должности.

## Сложные сопоставления и неоднозначности

- «И.о. прокурора Берестовицкого района» сопоставлено с прокуратурой Берестовицкого района Гродненской области по полному названию района.
- «Прокурора Вороновского района» сопоставлено с прокуратурой Вороновского района, не с соседней прокуратурой из-за частичного совпадения названия.
- «Барановичский межрайонный прокурор» сопоставлен с «Барановичской межрайонной прокуратурой»; «Пинский межрайонный прокурор» — с Пинской межрайонной прокуратурой.
- «Прокурор города Жодино» сопоставлен с городской прокуратурой Жодино, хотя в должности употреблено полное слово «города».
- «Брестский транспортный прокурор» сопоставлен с Брестской транспортной прокуратурой в том же региональном разделе.

Для 166 извлечённых строк неоднозначных сопоставлений не осталось; две межрайонные должности проверены отдельно по роду и населенному пункту. Незаполненная запись Брестского района отмечена отдельно выше.
