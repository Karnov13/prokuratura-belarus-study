# План обновления вкладки «Интерактивы»

1. Сверить JPEG по карте `docs/rebus-import-manifest.md` и скопировать 11 уникальных исходников в `assets/rebuses/`. Для каждого файла указать нейтральный идентификатор, размеры и ответ в `data/content.json`.
2. Заменить прежние задания во вкладке и в версии без JavaScript. Использовать отдельный нативный `details` для каждого ответа в обеих версиях. Связать изображение и ссылку «Увеличить» с оригиналом.
3. Применить к вкладке сетку по `docs/interactive-rebus-design.md`, сохранив полный кадр каждого JPEG. Обновить копирование ассетов в `scripts/build.mjs` и проверки в `tests/`.
4. Проверить 11 точных пар, отсутствие дубликатов, раскрытие и скрытие отдельных ответов, мобильную компоновку, сборку и доступность версии без JavaScript. Передать результат на ревью.

Готово, когда во вкладке доступны 11 оригинальных JPEG с верными ответами, начальным скрытым состоянием и независимым раскрытием. Все 11 JPEG входят в `dist`; четыре остальных раздела и эмблема сохраняются.

Проверки 15.11.2026. Все 11 тестов прошли. Сборка содержит 11 JPEG, каждый файл отдал HTTP 200 локально и побайтно совпал с оригиналом. Ответы сверены с картой импорта. В HTML версии без JavaScript есть 11 закрытых блоков `details`. Инструмент браузера не предоставил доступной вкладки. Браузерная проверка и снимок остаются открытыми.
